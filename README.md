# Ahmad Al-Smadi — Developer Portfolio

A clean, responsive developer portfolio built with React, Tailwind CSS, and Motion. Designed with a dark theme, smooth scroll-triggered animations, and a working contact form.

## Technologies

- **React 19** with Vite
- **Tailwind CSS v4** for styling
- **Motion** for scroll-triggered animations
- **Lucide React** for icons
- **Web3Forms** for the contact form (no backend required)

## Sections

| Section | Description |
|---------|-------------|
| **Navbar** | Fixed navigation with scroll spy and mobile hamburger menu |
| **Hero** | Name, role, intro, and CTAs (View Projects + Download CV) |
| **About Me** | Bio with education, field training, and current focus cards |
| **Skills** | Tech stack organized by category (Frontend, Backend, Databases, Languages, Tools) |
| **Projects** | Featured work: LapAdvisor, Real Estate, To-Do App |
| **Contact** | Contact cards + working form via Web3Forms API |
| **Footer** | Copyright and social links |

## Getting Started

```bash
# Install dependencies
npm install

# Create environment file
cp .env.example .env

# Add your Web3Forms access key to .env
# VITE_WEB3FORMS_ACCESS_KEY=your_key_here

# Start development server
npm run dev

# Build for production
npm run build
```
